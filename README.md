# 景区游览指南的程序性知识挖掘

2026《数据挖掘》课程探索性实验。项目从官方游览路线和游客游记出发，完成清洗、实体识别、路线结构解析、共指消解、条件建议抽取、知识图谱构建及旅游规划 Agent。

## 当前阶段

先交付 3 个景区各 1 条官方推荐路线、1 篇游客游记的开发样本，共 6 条。该样本用于项目 2—5 并行开发；完整语料继续在项目 1 中扩充。项目 2—7 目前仅建立目录与交接约定，尚未实现。

**当前先用黄山样本开发。** 黄山两条记录可用于首轮流程调试，仍需扩充和人工核验。故宫、西湖当前样本质量不足，暂作格式示例，后续补充或替换。现有数据均不作为最终效果评估集。具体读取方式见 [样本交接说明](docs/handoff.md)。

## 开始协作

1. 查看 `docs/` 中的原始任务书和 `docs/data_contract.md`。
2. 各模块统一读取 `data/processed/` 中的样本，以 `doc_id` 关联来源。
3. 实体位置以 `clean_text` 的 Python Unicode 字符索引为准，使用左闭右开区间 `[start, end)`。不要用 UTF-8 字节数或 JavaScript UTF-16 长度直接替代。
4. 将代码放入各实验的 `src/`，结果放入其 `outputs/`。自己的方法、人工检查和失败案例写入对应报告。
5. 接入完整数据前先在开发样本上验证读取、处理和导出流程；后续保持字段与文档编号稳定。

## 实验交付

| 项目 | 输入 | 主要输出 |
|---|---|---|
| 1 预处理 | 官方路线、游客游记 | 清洗数据、来源记录、质量检查 |
| 2 实体识别 | 清洗文本 | 三类实体、出现位置、词频图、规范表 |
| 3 路线结构 | 官方路线及游客游记 | 步骤与时间层级、可选路线对比 |
| 4 共指消解 | 游记与路线文本，可用项目 2 实体 | 人工标注、消解结果、效果评估 |
| 5 条件建议 | 清洗文本 | 条件—建议映射、分类去重及统计 |
| 6 知识图谱 | 项目 2、3，按需接入 4、5 | 节点、边、图谱文件与可视化 |
| 7 旅游 Agent | 项目 6 图谱 | 可调用的图谱工具、Agent、场景测试记录 |

## 评分与报告

每个项目独立按 100 分评分，另有按 100 分评分的探索性实验总结；最终汇总权重以教师说明为准。任务书允许等价技术路线、教师数据集和 LLM 辅助，要求代码、结构化输出、报告和验证证据相互对应。

总结需记录至少 2 个真实失败现象，并从方案局限中选择 1 个优先研究的技术点。请在实验过程中持续保存错误样例。

Final 任务书写明报告于 **2026 年 11 月 20 日 24:00 前**提交，具体提交邮箱见原始文件。实验安排和口径以授课教师通知为准。
