## 环境与运行

复用仓库根目录 `.venv`，Python 3.14.3、jieba 0.42.1 已安装；实验四无额外模型或API依赖。若另建环境，安装本目录 `requirements.txt`。

从仓库根目录运行：

```powershell
# 原五篇的四个版本对照、评价与复核表
& .venv/Scripts/python.exe experiments/exp04_coreference/src/run.py

# 全30篇v4预测、三组结果与最新误差分析；不生成正式实验报告
& .venv/Scripts/python.exe experiments/exp04_coreference/src/run_v4.py

# 语义和评价口径的回归测试
& .venv/Scripts/python.exe -m unittest discover -s experiments/exp04_coreference/tests -v

# 单独检查已有产物
& .venv/Scripts/python.exe experiments/exp04_coreference/src/verify.py
```

各阶段可独立运行：`detect.py` → `resolve.py --version v1/v2/v3/v4` → `evaluate.py --version v1/v2/v3/v4` → `review.py` → `verify.py`。源码不写入或修改实验二及实验一数据。`evaluate.py`仅对五篇人工标注计算严格指标，25篇的助手语义评价由`assess_v4.py`单独汇总。

检测支持 `--input`、`--docs`、`--outputs`；当前默认版本为v4，消解支持 `--version v1/v2/v3/v4`、`--samples`、`--input`、`--entities`、`--outputs`、`--max-distance`（v3回退默认400字符）。全量探索可用 `detect.py --docs all --outputs .cache/exp04_all`，再将 `--samples .cache/exp04_all/samples.json --outputs .cache/exp04_all` 传给消解脚本；原61项标注只覆盖默认5篇，不能把其指标当30篇的评价。

## 检测与位置约定

检测第三人称代词（它/他/她及复数）和指示词（这/那、这里/那里、此处/该园等）。不检测第一、二人称或完整的反身代词体系；“其他”“应该”“这样”“那么”“因此”等非目标词排除。词表内最长匹配，“它们”不再拆出“它”。

每次出现对应唯一 `sample_id = doc_id:start:end`，同句重复代词独立保存。位置使用 Python Unicode 字符索引、左闭右开，统一回溯原 `clean_text`；标注保存源文本哈希，文本改变会阻止使用旧偏移。句子按句末标点和换行切分，候选查找允许跨句、跨网页块。

## 四版消解方法

v1：400字符窗口内选择最近的名词候选，不区分人物、动物与地点，是对照基线。

v2：先检查后指引语、图像指示等无明确前文先行词情况，再按代词类型筛选候选；女性代词偏向明确女性名词，“它们”优先考虑附近动物；地点优先保留实验二具名候选，并参考站点标题、同句、当前地点和名词中心词。最近方向/距离提及降权；没有相容候选时返回空值。

候选基础分为 `50-字符距离/8`；同句+15，紧邻且间隔只有空白+40，实验二具名地点+12，当前站点同名候选+18，复数人群+25，中心词一致+30，当前位置动词+10，主语式表述+6；泛称-12，方向/距离提及-18。分数仅表示规则排序，不是概率或经过校准的置信度。每次使用独立分词器；规则不读取标注文件或 doc_id 特判。

v3：在原有规则上扩展完整路段（起终点、连续移动、跨行时刻记录）、箭头景点集合、状态变化事件和条件场景。结合名词中心词、概括句主语、图注场景和全园主题处理不同指代；复合地名保留完整边界，已确定为地点的名字修正后续POS误分，同名实体返回最近一次提及。

v3普通候选仍受400字符窗口约束；只有明确的全园游览讨论可回指文首景区主题。指路图注缺少道路先行词时拒绝强行匹配目的地。“该园”优先地址介绍的主语，排除地址中的城市或上级公园。新增规则位于 `src/context_rules.py`，不读取标注、不按文档编号或样本编号分支。v1/v2输出与人工标注的内容哈希均验证保持不变。

这些规则由已知开发错误类型归纳，并非独立测试。对复杂省略、隐喻或未覆盖的句法仍可能出错；当前开发集100%不能外推到新文章。

v4：`src/discourse.py`先按指代意图区分路线、事件、时间、文章、地点、人物、动物及植物拟人，再使用完整名词、并列群体、路线定义和小节主题选择对象。普通语义候选窗口500字符，小节主题最多回看1000字符；命名线路、标题和全文旅行可使用篇章级上下文。同句明确对象优先于较旧主题，v3回退候选保持独立，避免新增泛称污染旧排序。推理仅读取正文、元数据和实验二实体，不读取任何金标或助手裁定文件，不按文档编号分支。

v4的`antecedent`只存真实前文跨度；`referent`可补充篇章、标题或现场对象说明。`resolution_status=unresolved`表示未建立文字链接，带有`referent`时仍可能已有非文本对象说明；不能把链接率当作正确率。图片没有进入算法。新版本保留v1至v3产物，预测文件、指代关系和候选使用`_v4`后缀。

## 标注与人工复核

`annotations/gold_draft.json` 文件名为兼容原入口而保留，当前内容已是用户复核标注（annotation_kind=user_reviewed）。用户通读五篇原文后确认完成复核，在10处写下人工修改，其余51处按整份复核完成的声明确认。61项review_status均为confirmed，reviewer为用户，日期为2026-11-02。

原始助手初稿、修改前评价和用户亲笔批注文件原样保存在 `archive/human_review_20261102/`；10处修改逐字保存于 `outputs/human_review_import.json`，并记录修改前后字段与预测文件哈希。导入人工批注时保留了当时的算法和预测。之后根据开发错误改进为v3、v4，各版预测分别保存，始终对照同一份人工标注；本次一致性整理不改算法、标注或预测。

用户的10处修改涉及图片中的路口、桥、游览图，以及指示限定、时间指示和诗词景观等用法。对应的reference_kind、referent_description和human_interpretation保存含义；有可定位前文提及时保留真实字符范围，无正文前置对象时保持空链接。第25处的现场石刻与前文“大观峰区域的石刻”一致，因此保留该文字提及并补充指示限定用法。

当前仍有51项正文回指与10项没有正文前置对象的用法。空链接正确只表示算法没有错误地链接到前文，不能证明它理解了图像或现场含义。人工复核没有为正文补写原本不存在的词语或位置。

`outputs/gold_review.md` 显示更新后的五篇完整原文标注；技术对照表保存在 `outputs/gold_review_details.md`。后续可继续按编号修改，更新标注后单独重跑评价与复核表，不必重跑或改变预测。

评价同时保存reference_comparison（当前标注）、human_reviewed_evaluation（人工确认子集）和assistant_draft_comparison（归档初稿对照），三者不互相冒充。人工复核完成不等于独立测试，语料仍是规则开发使用的同批文本。

## v4的25篇与总体评价

固定参考仍为`annotations/remaining25_assistant_draft.json`，143项全部保持pending。逐项助手语义判定另外存于`annotations/remaining25_v4_assessment.json`；其哈希绑定参考、预测与人工金标。`assess_v4.py`只汇总已审阅判定，不是自动判断任意新预测对错的模型。预测或参考变化后必须重新查看差异并复评，脚本拒绝沿用旧分数。判定文件不参与推理。
