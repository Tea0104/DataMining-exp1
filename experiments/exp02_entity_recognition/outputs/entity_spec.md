# 景区实体定义规范表（实验二 · selected_v2）

本规范用于把游览文本中的实体统一为三类：**景点 POI、交通方式、时间节点**。
`src/config/lexicon.json` 是它的机读版本，`src/recognize_entities.py` 只负责按本表执行。
覆盖泰山（`TAISHAN`）、张家界武陵源（`WULINGYUAN`）、净月潭（`JINGYUETAN`）三景区共 30 篇。

## 1. 位置口径

- 文本来源：`data/processed/full/selected_v2/dataset.json` 的 `clean_text`，**不再二次清洗**。
- `start` / `end` 为 Python Unicode 字符索引，左闭右开，必须满足 `clean_text[start:end] == text`。
- 一条实体对应一次出现（mention），同一名称出现多次即多条；名称级去重只在统计时使用。

## 2. 三类实体定义

### 2.1 景点 POI

判定依据：**能被「到、去、经、住、游览」支配，且有可识别名称的地点**。

| 子类型 | 说明 | 示例（按景区） |
|---|---|---|
| `peak` | 有名称的山峰 | 玉皇顶、天烛峰 / 御笔峰、乾坤柱 / 观潭山 |
| `gate` | 门、坊、入口、门票站 | 中天门、岱宗坊、红门 / 东门门票站、南天门 |
| `temple` | 寺、庙、祠、宫 | 碧霞祠、斗母宫、普照寺 |
| `pavilion` | 亭、阁、榭 | 壶天阁、青阳堂、甘泉榭 |
| `trail` | 有名称的步道或路段 | 十八盘、回马岭、东御道 / 十里画廊、空中走廊 |
| `water` | 溪、潭、瀑、湖、湾 | 彩石溪、黑龙潭 / 金鞭溪、紫草潭 / 月亮湾 |
| `cave` | 洞穴 | 黄花洞、莲花洞 |
| `landmark` | 地标性石、松、碑、桥 | 拱北石、五岳独尊石、姊妹松 / 天下第一桥 |
| `viewpoint` | 有名称的观景点 | 瞻鲁台 / 迷魂台、摘星台 |
| `area` | 片区、峡谷、园区 | 后石坞、桃花源 / 天子山、袁家界、西海 / 森林浴场 |
| `facility` | 广场、场馆、营地、乐园 | 汉阙广场 / 大氧吧广场 / 女神广场、中国瓦萨博物馆 |
| `station` | 车站 | 泰山站、泰安站 |

### 2.2 交通方式

判定依据：**能与「乘坐、坐、走、骑」搭配，回答「怎么移动」**。

| 子类型 | 说明 | 示例 |
|---|---|---|
| `cableway` | 索道、缆车、地轨 | 索道、缆车 / 天子山索道、黄石寨索道 |
| `lift` | 垂直提升设备 | 百龙天梯 |
| `shuttle` | 摆渡车、观光车、大巴 | 环保车、观光车、旅游大巴 |
| `bus` | 城市公交 | 公交车、公交 |
| `rail` | 铁路 | 火车、高铁、地铁 |
| `train` | 景区小火车 | 观光小火车、小火车 |
| `taxi` | 出租车 | 出租车 |
| `self_drive` | 自驾 | 自驾、自驾车 |
| `walk` | 步行游览 | 徒步、步行 |
| `boat` | 水上交通 | 竹筏、游船、画舫船 |

### 2.3 时间节点

判定依据：**能回答「什么时候」或「花了多久」，且不是计量单位本身**。

| 子类型 | 说明 | 示例 |
|---|---|---|
| `period` | 时段 | 凌晨、早上、上午、中午、下午、傍晚、晚上、`14:13`、`9点54分` |
| `event` | 以自然事件表达 | 日出、日落 |
| `day` | 行程日 | 次日、第二天、当天 |
| `duration` | 行程时长 | 半天、一日、两天 |
| `clock` | 显式时刻 | `23:00`、`4:13`、`11:27` |

## 3. 边界规则

1. **最长匹配优先**：`天子山索道` 不拆出 `天子山`；`天下第一桥` 不拆出 `第一桥`。
2. **景区本体名不计 POI**：`泰山`、`净月潭`、`张家界` 是语料主题而非路线节点，只作为筛选维度。
   例外是 `武陵源`，原文用它指住宿与集散城镇，按 `area` 计入。
3. **交通设施不单独成实体**：`索道站`、`索道下站`、`门票站` 不另计；`东门门票站` 属具名入口时计入 `gate`。
4. **交通方式与 POI 不重复计**：`天子山索道` 只计交通方式，对应的山体另由 `天子山` 表达。
5. **通名不标**：`观景台`、`平台`、`广场`、`山顶`、`山峰`、`山谷`、`大门`、`入园` 等无名称词一律不计。
6. **计量单位不计时间**：`小时`、`分钟`、`全程` 单独出现时不标，只有 `4--6小时` 这类带数字的时长才由上下文承担；
   本版仍不把「数字 + 小时」整体标为时间节点，避免与费用、距离混淆。
7. **时刻必须有分隔符**：`4:13`、`23:00`、`9点54分` 计为时刻；裸四位数字（`2023`、`115`、`7000`、`2078`）不计。
   这是 v1 的主要错误来源。
8. **路线产品名不计时间**：`一日游`、`两日游` 属产品名。
9. **景区外地点不计**：`凤凰古城`、`天门山`、`长沙`、`武汉` 等跨景区或跨城地点不计 POI。
10. **不为凑数补写**：原文没有的时间、条件、先行词一律不补；推断值另标 `inferred`（本版未使用推断）。

## 5. 易混淆对照

| 原文表达 | 正确标注 | 常见错误 | 原因 |
|---|---|---|---|
| 天子山索道 | TRANSPORT / cableway | 拆成 `天子山` + `索道` | 长词未进词典 |
| 泰山 | 不标注 | 记为 POI | 景区本体名，全篇出现 |
| 十八盘 | POI / trail | 漏识或无后缀可依 | 无典型后缀，靠词典 |
| 袁家界、杨家界、黄石寨 | POI / area | 漏识 | 后缀是「界」「寨」，不在宽后缀表内 |
| 4:13、23:00 | TIME / clock | 漏识 | v1 只按数字长度判断，不认冒号 |
| 2023、115、7000、2078 | 不标注 | 记为时刻 | 裸数字被当成四位时刻 |
| 徒步惊喜 | POI | 误标 `徒步` | 名称本身含「徒步」，边界切错 |
| 景区正门 | POI / gate | 可判可不判 | 通名，但在路线里是起终点节点 |

## 6. 记录字段

| 字段 | 说明 |
|---|---|
| `doc_id` / `scenic_id` | 文本与景区编号，可回溯 `selected_v2_sources.json` |
| `text` | 表面形式，必须等于 `clean_text[start:end]` |
| `entity_type` | `POI` / `TRANSPORT` / `TIME` |
| `subtype` | 上表语义子类型 |
| `granularity` | `specific` 具名 / `generic` 泛称 / `unknown` 词表未收录 |
| `canonical` | 上位类别，**不可作为实体 ID 或图谱节点 ID** |
| `start` / `end` | 左闭右开字符索引 |
| `sentence_id` | 所在句编号 |
| `method` | `lexicon` / `suffix` / `keyword` / `number` / `regex_clock` / `regex_point` / `regex_day` |
