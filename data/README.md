# 开发样本数据

`sample_v1` 包含故宫博物院、黄山风景区、杭州西湖风景名胜区各 1 条官方路线和 1 篇真实游客游记的选定正文，共 6 条记录。游客内容取自真实作者文章，不使用生成文本替代。

这是项目 2—5 的首轮开发输入。完整语料仍需继续采集，先按每景区 1 条官方路线及 5 篇游客游记准备。

当前优先使用黄山两条记录进行开发；故宫、西湖样本质量不足，暂作格式示例，后续补充或替换。现有数据尚未完成最终质量验收，不用于报告最终准确率或泛化性能。

## 文件

- `raw/sample_v1/*.json`：6 份经确认的正文范围、原始 HTML 片段与来源元数据。
- `processed/sample_v1.json`：统一输入，包含 `raw_text` 与 `clean_text`，可直接使用 Python `json` 读取。
- `processed/sample_v1.jsonl`：相同记录的逐行 JSON 格式。
- `processed/texts/`：每条清洗后文本的独立 UTF-8 文件。
- `metadata/sources.json`：来源、日期、取用范围、获取方式、许可和内容哈希。
- `metadata/quality_report.md`：各条文本长度、完整性检查和使用限制。

字段定义及下游输出约定见 `../docs/data_contract.md`。

## 正文选取与清洗

先人工确定正文或路线章节的范围，再执行确定性清洗。这两个步骤分开记录：章节取舍属于采集范围选择，空白、标签和控制符处理属于清洗。

- 故宫官方：官网 `POST /ajax/get/guides.html`，参数 `linkage_id=990120`、`linkage_name=follow_route`，取响应 `data.description`。不保存响应中的临时令牌。
- 故宫游记：选取 `article.joe_detail__article`，排除图片文件，保留文字题注。
- 黄山官方：仅取“（1）一日游线路”，未复制整篇介绍。
- 黄山游记：选取 `div.post-content` 下“T 爬山”至返程的游览叙述，排除“风景区星级”“运输”专题及外部 `blockquote` 引文，排除图片与视频。
- 西湖官方：取“室外徒步 独爱大荷区（北线）”的路线、半天建议和1.5—2小时的时长信息，范围中未包含整段宣传描写。
- 西湖游记：选取 `div.post-content` 下“11.9-11.13 杭州”至“结”标题之前的正文，不收录网页AI摘要。

自动清洗保留正文表述、序号、路线连接符、时间、条件、代词和表情，处理 HTML 标签、脚本样式、正文网址、空白换行与技术性控制符。正文网址保留在 `raw_text`，来源 URL 始终保留在元数据。原文中的误字和景点称呼不擅自纠正。

## 使用边界

6 条文本约 4 千字，适合验证数据读取、规则与 Prompt、位置索引和结构化导出。故宫游记较短；共指和条件表达主要集中在黄山游记。后续应补充更多景区、游客类型和天气条件，单独安排人工评估样本。

官方路线没有给出完整的上午／中午／下午安排，不补造时刻。游记同时含有计划路线、实际路线、未到访景点、图注及周边地点，后续抽取时需区分。

## 复现

在仓库根目录运行：

```bash
python experiments/exp01_data_preprocessing/src/preprocess.py
```

该步骤仅依赖 Python 标准库，使用随包快照离线重建清洗数据及质量报告，不受原站改版影响。重新尝试下载候选来源可运行 `collect_sources.py`，其结果与已确认正文快照分开保存。
