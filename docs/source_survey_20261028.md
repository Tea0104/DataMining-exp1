# 项目1：数据来源可行性调查

调查日期：2026-10-28，Asia/Shanghai。

这是前期来源可行性调查。组长后续确认采用定向选源采集，当前实施方案及30篇来源见 [selected_v2选源记录](selected_v2_source_selection.md)。

## 本轮结论

**游客游记优先采用携程旧游记，去哪儿移动端作为补充；官方路线先核查张家界世界地质公园站的候选文章。** 该站的独立域名身份确认仍需补强，暂不直接验收为正式官方语料。小红书、马蜂窝先保留为备选。本轮先确定采集入口和筛选依据，尚未确定最终三个景区，也未交付正式30篇语料。

按组长确认的口径，正式目标为 **3个景区 ×（5篇官方路线文章 + 5篇游客游记）= 30篇**。同一文章内的几套路线、按天分出的章节、转载副本，不自动增加独立文章数。此前“每景区1条官方路线”的完整采集计划已更正。

本轮保存了38个不同URL的HTTP探测记录，其中35个是网页入口或详情，3个是robots文件；另做普通匿名浏览器核查。这里只是低量可行性验证，不能据此认定大规模采集长期稳定。候选链接数、可访问正文数、最终合格篇数分别统计。

## 下一轮候选池与简单筛选方案

以下是工程方案建议，不是教师新增要求，也未声称已经采集完成。

1. 每个候选景区尽量发现8—12篇官方路线文章、30—50篇游客游记。官方供给不足或无法取得正文时，继续补来源或替换景区。
2. 从列表自动发现详情链接，按平台文章编号规范化URL；保存来源页、发现日期、请求状态。随后低频获取详情，保留原始正文范围和下载哈希。
3. 先排除登录页、验证码页、空正文、软404、完全重复记录。仅有HTTP200不能通过此关。
4. 用景区POI种子词、移动动词、路线连接符、时长与时段等可解释规则，标记景区相关性和路线信息。游客正文很短（例如不足800个汉字）先送复核，避免把照片列表当长游记；官方路线不照搬此长度门槛。
5. 商业作者、导游联系方式、套餐售卖等作为广告复核信号；跨景区长文标记待定位相关章节。不能只因为文章出现在某景区列表中就直接收录。
6. 规范化正文哈希检查完全重复，再用字符5-gram相似度找近重复。原文有共同路线不一定应删除，但需检查是否仅为同一模板或转载副本。
7. 从候选中保留天气、季节、游客类型、交通方式、游览时长的差异。实际经历、计划路线、备选方案分别标记；不要求每篇同时具备所有任务2—5的语言现象。
8. 人工复核通过后，每景区选5篇官方文章与5篇游客游记，再进入清洗及结构化整理。跨景区章节可作为分析单元，但同一原文不能拆成几篇凑数。

每个淘汰或待复核项记录 `reason_codes`，例如 `login_gate`、`empty_body`、`off_scenic_scope`、`short_body_review`、`ad_review`、`near_duplicate_review`。报告可展示“发现多少→取得正文多少→各原因淘汰多少→最终多少”的实际筛选过程。先抽查少量候选校准规则，再扩大规模，不在看到最终实验效果后倒改选择标准。

## 本轮文件与复现

- `data/metadata/source_survey_20261028.json`：38个URL的状态、候选链接、12篇路线正文长度、重复提示、来源身份核查和浏览器观察；不含文章全文。
- `data/metadata/source_probe_targets_20261028.json`：探测清单。
- `experiments/exp01_data_preprocessing/src/probe_sources.py`：仅用Python标准库的小规模探测入口，输出整页指标，供人工继续核对正文。

在仓库根目录运行单个入口验证：

```bash
python experiments/exp01_data_preprocessing/src/probe_sources.py --only ctrip_huangshan_list
```

省略 `--only` 会顺序访问完整清单，每次请求至少间隔2秒。新结果放在 `data/downloads/source_probe/`，不会覆写这次调查快照；原站改版、访问状态变化可能使重跑结果不同。浏览器登录跳转、滚动加载观察不由该HTTP脚本自动复现。

携程本次取得的robots文件未列出无查询参数的 `/travels/` 路径禁令，但列出了 `/ajax` 和带查询参数URL等限制。本轮使用公开文章及列表路径；后续批采需按当时实际规则控制范围和频率。去哪儿移动端、张家界站点的robots地址本次返回404，仅记录响应，不据此推定转载或公开分发许可。

本轮原始HTML仅留在本地工作缓存；公开仓库只加入来源调查和元数据。后续语料的署名、使用与分发范围另按各站规则确定，不因可访问而自动获得开放许可。

既有 `sample_v1` 开发数据及公共字段接口保持原状，同学仍可继续开发。本轮调查不作为正式语料数量或清洗完成的验收证据。
