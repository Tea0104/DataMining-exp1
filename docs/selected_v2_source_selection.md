# selected_v2：三个景区的定向选源与原始采集

2026-10-28。当前阶段：30篇来源已选定并完成原始获取；正式清洗、景区章节分离及下游交接尚待完成。

当前范围：按组长决定，仅处理网页文字正文、标题和有信息的文字图注。取消图片下载、OCR和读图补充的后续计划；图中独有信息不纳入本次语料，也不补推不存在于文字中的路线、距离或时长。

## 采用的方案

按组长确认，先人工查找适合课程项目的景区官网路线和携程游记，再整理为固定URL清单，用爬虫程序获取。报告记录为“人工定向选源＋按清单采集”，重点放在正文提取、清洗、去重、范围控制和质量验证。

选定 **泰山风景名胜区、张家界武陵源核心景区、净月潭国家级风景名胜区**。每个景区5篇官方路线文章和5篇携程游客游记，共30个独立文章URL；没有将单篇的不同章节拆成多篇凑数。

## 清洗前已发现的问题

1. **8篇跨景区游记**：例如张家界游记同时写天门山、凤凰和长沙，吉林游记还写长白山。下载保留全文，正式输入需定位武陵源或净月潭章节；保留段落与原文的对应关系。
2. **5篇短官方路线**：净月潭5篇仅73—169个非空白字符，但有明确的节点及路线顺序，按短路线材料保留。不能用游客长文门槛统一删除。它们适合路线及实体任务，不能承担大量共指样本。
3. **4篇日期差异**：列表发表日期与详情显示日期不同。分别保存两种字段及来源，暂不认定哪一个代表首次发表或修改。
4. **2篇有重复段落或图注组**，另有2篇含零宽等技术性Unicode字符；2篇游记低于800汉字，标记复核而非直接删除。
5. 携程正文有直接段落、标题、图片题注和包装容器等不同结构；公告、文章元信息、页脚与正文分开定位。泰山列表的文章链接嵌在公开HTML的CDATA记录中，单纯忽略script的通用提取器会漏掉列表项。

下一步按顺序处理：确定景区章节范围 → 去除结构噪声与非正文媒体 → Unicode和空白规范化 → 按图注角色复核重复 → 检查日期与必填字段 → 输出JSON/JSONL、逐条文本和质量报告。原文的路线分支、折返、代词、时间和条件应保留；原文称呼、错误或未验证建议另记疑点，不擅自改写成事实。

上述问题目前属于待清洗标记，不是最终清洗效果或算法准确率。旧 `sample_v1` 仍供同学开发，新版本尚未切换为默认下游输入。

## 实际筛选依据

采用数量覆盖、正文可获取、路线信息、实际经历和场景差异作为选择依据。已人工排除或留作备选的案例包括：小包团推广、私人定制行程销售、主要为酒店体验的文章、目标景区信息较少的短文，以及更偏建议行程而非实际经历的文本。排除条目与检查阶段保存在 `data/metadata/selected_v2_source_review.json`；仅看到列表片段的条目标记为列表初筛。

## 文件和复现

- `data/metadata/selected_v2_sources.json`：30篇来源、正文定位规则、选择理由和范围提示。
- `data/metadata/selected_v2_source_review.json`：实际筛选记录与备选说明。
- `data/metadata/selected_v2_acquisition_report.json`：逐篇获取状态、字符数、日期差异、复核标记和哈希。
- `data/downloads/selected_v2/`：本地原始响应及HTTP元数据。
- `data/raw/full/selected_v2/`：本地提取正文HTML、未归一化文字和元数据，尚无 `clean_text`。

在仓库根目录执行：

```bash
python -m pip install -r experiments/exp01_data_preprocessing/requirements.txt
python experiments/exp01_data_preprocessing/src/capture_selected_sources.py
python experiments/exp01_data_preprocessing/src/capture_selected_sources.py --offline
```

首次按清单获取，每次请求起始时间间隔至少2秒；以后优先读取并校验本地响应快照。显式加 `--refresh` 才重新请求原站；原站页面可能变化，不保证刷新后的内容哈希与这次相同。

原始响应与文章全文仅保存在本地被Git忽略的目录，当前可入库的是采集代码、来源清单、筛选说明和统计。本文没有将第三方文本重新声明为开放许可，也未将待清洗原文当作最终训练或评估数据。
