# 实验文档

`rubrics/` 保存用户提供的两份原始 Word 任务书，未修改其内容。

- `Final` 版包含实验主题、提交截止时间和两个班的提交邮箱。
- `XK` 版的实验内容和评分标准与 Final 版一致，未包含上述提交信息。
- 项目 1 按本组确认的采集口径执行：3 个景区，每景区 5 篇官方路线文章、5 篇游客游记，共 30 篇；单页内多个路线章节不自动算作多篇。
- 项目 3 附加题分数栏为 20 分，细目合计为 30 分；具体加分方式以教师解释为准。

`data_contract.md` 约定项目 2—5 的公共输入。该约定属于本组工程组织方案，不替代教师评分要求。

`source_survey_20261028.md` 记录教师推荐平台与备选来源的访问实测、候选覆盖、限制和下一轮筛选方案。调查记录与正式语料分开保存。

`selected_v2_source_selection.md` 为后续采用的实施方案：人工定向选择泰山、张家界武陵源、净月潭各5篇官方路线和5篇携程游记，再按清单程序采集。逐篇选源表和原始获取结果与前期可行性调查分开记录。

当前按组长决定仅处理网页文字正文及有信息的文字图注，不开展图片下载、OCR或读图补充。`image_information_plan.md` 仅保留前期调查记录，方案已取消，不属于当前实施流程。

正式30篇数据已完成，`../reports/exp01_report.md`提供按评分项对应的方法、统计与复现证据。`handoff.md`与`data_contract.md`现以selected_v2为准；历史调查和取消的图像方案不属于当前必跑步骤。
